# Τι πρόγραμμα να βάλω;

Οδηγός προγραμμάτων πλύσης για το πλυντήριο των 5 kg, φτιαγμένος από τον
πίνακα προγραμμάτων του φυλλαδίου. Εγκαθίσταται ως PWA και δουλεύει offline.

Διαλέγεις τι έχεις στον κάδο (12 κατηγορίες) και σου δείχνει:

- ποιο πρόγραμμα να γυρίσεις — με το σύμβολο του πλυντηρίου, όπως στον διακόπτη
- θερμοκρασία (προεπιλογή + επιλέξιμο εύρος)
- στροφές στυψίματος, μέγιστο φορτίο
- τι μπαίνει στη θήκη 1 / θήκη 2
- ποιες λειτουργίες μπορείς να προσθέσεις (καθυστέρηση, θερμοκρασία, ταχύτητα, επιπλέον ξέβγαλμα)
- σημειώσεις προσοχής από το φυλλάδιο (90°C μόνο για υγιεινή, λιγότερο απορρυπαντικό στο Rapid 14)

Κάτω-κάτω υπάρχει ολόκληρος ο πίνακας των 12 προγραμμάτων όπως στο φυλλάδιο.

## Τρέξιμο

```
start.bat            # ή: node serve.js  [port]
```

Ανοίγει το http://localhost:4720/ . Χρειάζεται σερβίρισμα από http(s) — από
`file://` η σελίδα δουλεύει κανονικά, αλλά **δεν** εγκαθίσταται και δεν έχει
offline cache, γιατί ο service worker δεν επιτρέπεται σε `file://`.

## Εγκατάσταση (PWA)

Στο localhost ο browser δίνει «Εγκατάσταση» (και η σελίδα δείχνει δικό της
κουμπί όταν ο browser το προσφέρει). Μετά την πρώτη φόρτωση όλα τα αρχεία
του κελύφους μπαίνουν στον cache, οπότε ανοίγει και χωρίς δίκτυο.

Για εγκατάσταση **στο κινητό** δεν αρκεί το `http://192.168.x.x:4720` — το
service worker θέλει secure context, δηλαδή https ή localhost. Επιλογές:
GitHub Pages / Vercel για το repo, ή ένα tunnel προς τον υπολογιστή.

Οι συντομεύσεις του manifest (long-press στο εικονίδιο) πάνε κατευθείαν στην
Καθημερινή μπουγάδα, στα Λευκά και στο Rapid 14.

## Αρχεία

| Αρχείο | Τι είναι |
| --- | --- |
| `app.html` | **Η πηγή** του περιεχομένου, χωρίς `<html>/<head>` — αυτό δημοσιεύεται ως Artifact. |
| `build.js` | Χτίζει το `index.html` από το `app.html` + το PWA wrapper (`node build.js`). |
| `index.html` | Παράγεται. Μην το αλλάζεις με το χέρι. |
| `manifest.webmanifest` | Όνομα, εικονίδια, χρώματα, συντομεύσεις. |
| `sw.js` | Service worker: precache του κελύφους, stale-while-revalidate, cache και για τις γραμματοσειρές. |
| `serve.js` / `start.bat` | Static server χωρίς εξαρτήσεις, στο :4720. |
| `icons/` | Εικονίδια PWA — παράγονται από το `tools/gen-icons.py` (Pillow). |

Μετά από αλλαγή στο κέλυφος, ανέβασε το `CACHE` στο `sw.js` ώστε να πεταχτεί
ο παλιός cache.

Deep link: `index.html#jeans` ανοίγει απευθείας την απάντηση για τα τζιν
(ids: mixed, whites, shirts, jeans, sport, wool, delicate, hygiene, quick, eco, cold, drain).
